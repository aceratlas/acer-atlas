# Acer Atlas v2.7 — collectie centraal

Testversie gebaseerd op de aangeleverde v2.6-bestanden.

- Database bevat 58 cultivarrecords.
- De cultivaromschrijving staat onder **Informatie** in de collectie en op het cultivarprofiel.
- De zichtbare versie is v2.7. De service-worker-cache is vernieuwd.
- De bestaande lokale opslagcode is behouden; deze testbuild bevat geen opdracht om browseropslag te wissen.
- Cultivarfoto’s zijn nog niet allemaal individueel geverifieerd en gekoppeld. De database markeert ze daarom als `needs_verified_photo` in plaats van een verkeerde foto te tonen.

## Uploaden naar GitHub Pages
Upload alle bestanden in deze map naar de hoofdmap van de repository en vervang bestanden met dezelfde naam. Commit en wacht tot GitHub Pages klaar is. Test eerst op een apparaat waarop je geen onvervangbare collectiegegevens hebt. Verwijder of wis geen sitegegevens uit je bestaande browser.
